# Flip

A lightweight, mobile-friendly image switcher. It runs in the browser without a server or dependencies.

## Use it

1. Open `index.html` (not `viewer.html`) in a browser on your phone or computer.
2. Choose your first image, then your second image.
3. Optionally choose an audio file. It loops only while you press an image and stops when you release.
4. Tap **Open full screen**.
5. Press and hold the image to show the second picture. Release to return to the first. Tap **Back** to return to image selection.

The images stay on your device and are not uploaded. The optional `viewer.html` file redirects to `index.html` for anyone with an old viewer link.
